## 客户端联合更新

- Java、Go、.NET CLI：统一命令易用性、生命周期诊断、认证错误处理及状态查询行为，详见 #39。
- Windows 桌面客户端：网络变化和睡眠恢复触发重连，提供立即重试与托盘后台/退出选择；保留具体错误原因，区分控制认证和转发通道就绪。
- Windows 界面默认展示共享服务，配置与诊断分层，日志折叠；改善小窗口分页和操作按钮布局。
- Android：按 VPN/非 VPN 用途调整前台服务类型；增加网络变化重连、有界多地址连接、错误分类、后台状态/消息/草稿恢复。
- Android 互传增加在线设备选择与单条消息结果，失败保留内容，不把提交当作送达；ACK 结果未知时不自动重复发送。页面按设备、互传和设置分区，支持明暗主题、键盘避让和更大的触控目标。
- 本次沿用全端发布流程，同时提供服务端及 STUN 构建；本次发布不代表已部署到运行中的服务器。

## 已知限制与待验收

按维护者决定先发布，图形客户端验收跟踪 #40 **保持开放**：

- Android 15+ 真机 VPN/非 VPN 长期后台、Wi-Fi/蜂窝切换，以及 Windows 真实睡眠恢复、托盘退出和高 DPI 交互尚未完成全面验收。
- Android 模拟器和 Windows 离屏布局截图不替代真实设备测试；尚未测量首次连接成功率、长期在线率或通道就绪后的服务可访问率。
- Android 消息只保留本次应用进程最近 100 条；退出进程后的历史不持久化。手动重发前应确认对方未收到；“已提交”不表示已送达或已读。
- 非 VPN 常驻服务使用 specialUse；如通过 Google Play 分发，仍需相应用途审核。
