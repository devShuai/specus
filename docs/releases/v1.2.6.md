## 三端 CLI 本地管理页

- Java / Go / .NET 新增 `ui --config PATH [--no-open] [--port PORT]`，使用同一份离线页面资源，不需要安装桌面客户端或 Node 服务。
- 支持首次配置、离线校验、保留 JSONC 注释及未知字段的保存、显式连接/断开/重新连接；保存不会自动登录或改变运行中的连接。
- 凭据不回显，留空保留原值或 env:/file: 引用；通过内容版本检查防止覆盖外部修改，使用私有临时文件及原子替换。
- 管理端口仅监听 127.0.0.1，采用一次性连接码及内存会话，校验 Host/Origin，不开放通用文件、命令或代理接口。
- 三端共用同配置管理锁；其他 CLI 实例仅只读展示，不接管、不误停。关闭浏览器不停止隧道，退出管理服务会取消其拥有的连接。
- 区分 HTTP 登录、控制认证和转发通道就绪；设备/服务目录不表示目标业务已通过可达性探测。

## 其他修复及分发

- Java / Go / .NET 开发构建不再误提示降级到正式版；Windows 桌面客户端修正字体字重、回退及下拉框文字渲染。
- Java Tomcat 更新到 11.0.25；修正 C server 测试脚本向严格 CLI 传递无效 Spring 参数的问题。
- 沿用全端发布流程，提供客户端、服务端、STUN 与签名 Android 包；发布不代表已部署到运行中的服务器。
- Homebrew cask 随本次发布更新 Mac arm64 / x64 的 Go CLI。安装后运行 `specus-client ui --config ./client.jsonc`；已有安装可执行 `brew update` 和 `brew upgrade --cask specus-client`。

## 验证与已知限制

- 本地回归：Go 三个包通过；Java 客户端 136 项通过、1 项 Windows 权限机制相关跳过；.NET 客户端 340 项通过。
- 三端 Windows 真实进程与 Chrome 基础矩阵各 38 项，并验证跨语言竞争锁；WSL Ubuntu 三端各 29 项，包含 SIGINT 与锁清理。Java/.NET 原有 CLI Windows 矩阵各 32 项通过。
- 按维护者要求，#41 以本地管理页 v1 的三端交付关闭，不将扩展需求或未测场景伪装为已完成。更多高级配置、主动诊断/安全日志、SSH 体验、macOS 浏览器/读屏及 Windows 控制台人工验收仍属后续工作。#40 的原生 GUI 真机验收保持独立。
- 首期页面只编辑服务地址、凭据及 noop/auto 网卡模式，复杂字段使用外部编辑器。刷新需用终端新连接码重新授权；stdin 已关闭或会话达到上限时需重启管理服务。遗留管理锁需确认原 PID 退出后手动清理。
- 本地页面不是公网或多人管理后台；不支持接管已有 CLI、服务安装或互传。详细安全和生命周期边界见 [CLI 使用说明](../cli-usage.md)。
