Specus v2.1.0 是一次网页界面版本：管理后台与公开页面改用设计规范自己的组件重写，互传页重新设计。服务端、客户端的协议、配置与数据库都没有变化，v2.0.0 的客户端与本版服务端互通。

## 管理后台

- 外框：
  - 侧栏是浮起的玻璃面板，可以收起成只剩图标，底部是「跟随系统 / 浅色 / 深色」外观切换。
  - 顶栏透明，搜索框找页面与常用操作（`/` 或 Ctrl/⌘ K 打开，方向键选择，回车进入），右上角是帮助与个人菜单的圆按钮。
  - 页面上方是同组页面的区域页签，例如客户端、消息、端口映射、HTTP 路由、客户端下载之间一键切换。
  - 手机上侧栏收进左侧抽屉。
- 每个页面按同一结构排布：页头（标题、一句说明、页面操作）→ 视图页签 → 带区块标题的内容。数字卡只放在数字是重点的页面顶部；表格在手机上叠成一条一条；列表上方是玻璃筛选条和结果数。
- 时间写法统一：24 小时内写「3 分钟前」，悬停显示完整时间，更早的写 `2026-10-23 16:02`；用时写「3 分 20 秒」。状态一律是带文字的标签，出错提示写原因和下一步。
- 工作台：待处理问题逐条写清下一步与受影响的服务；常用与最近打开是紧凑的行；全部服务是带类型与设备状态的表格。
- 概览：一排数字卡；日流量图可以在图表和表格之间切换，悬停或用方向键查看每天的数值；客户端流量排行带占比条。
- 流量使用：HTTP 记录用玻璃筛选条检索，仍是点「搜索」或回车才发起查询；详情对话框、TCP 帧与媒体采集列表同样改版。
- 连接记录：按客户端、结果与时间范围筛选，结果标签与在线时长，分页。
- 客户端：带编号的接入步骤，只按已读取的数据标记完成与下一步；接入凭证与实例表格，危险操作放在最后。
- 消息：左侧客户端列表、右侧对话；附件是文件行，上传时显示进度。
- HTTP 路由：发布表单的访问范围改为「受保护访问 / 公开访问」两张选项卡片；连通性检查按「已配置 → 设备在线 → 目标可达 → 访问成功」逐段显示，停在哪一段就写那一段的下一步；分享与编辑对话框随之改版。
- 私有组网：顶部四张数字卡（全局开关、设备、会话、直连占比），下面是设备、服务、出口分流、活跃会话、ACL、NAT 诊断的视图页签；NAT 诊断分阶段给出结果。
- 系统管理、产品指标、客户端下载与帮助文档同样改版；帮助文档的快速开始是编号步骤，代码块带复制按钮，常见问题可以折叠。

## 公开页面

- 落地页保留引水渠主视觉，下面是能力卡片、拓扑与原理卡片；去掉了背景网格、扫描线与数据包动画。
- 登录 / 注册对话框改为 44px 的大输入框、登录与注册的分段切换、整宽主按钮，错误以提示条显示。登录方式、OIDC 流程与校验不变。
- 客户端下载页先给出与当前设备匹配的安装方式（macOS 为 Homebrew 命令卡片），展开后每个平台一张表格，带架构、版本、大小与可复制的 SHA-256。
- NAT 检测：检测球保留，结果、难度量表与验证链路改为卡片与分阶段列表，高级设置可以折叠。
- 临时 HTTP 分享的落地页改为居中的状态卡片，写明原因和下一步。

## 互传页重新设计

- 页面就是三步：选择接收方 → 选择内容 → 发送。
- 接收方是设备卡片，显示名字、末 4 位标识与「直连 / 中继 / 连接中 / 离线」标签，可以用方向键选择。正在寻找时显示「正在寻找附近设备」，发现失败时给出重试与输入配对码。房间里只有自己时，二维码与配对码直接显示在页面上。
- 选择内容分「文字与链接 / 文件 / 多人白板」：
  - 文件先进入待发送列表（类型图标、大小、移除），按发送按钮才发出；发送按钮写明会发生什么，例如「发送 3 个文件给 Beta · 9ef7」，不能发送时写明原因，例如「先选择接收设备」。
  - 文件可以拖到页面任意位置，遮罩会写明要发给谁，Esc 取消；在页面任意位置粘贴只加入待发送内容，不会自动发出；文字框里 Ctrl/⌘ Enter 发送。
- 传输任务直接列在页面上，显示进度、速度、剩余时间与已用时间，可以取消或重试；可续传的传输用同样的样式。原来的「传输任务」弹窗与设备操作面板不再需要。
- 收到的文件和文字进入「收到的内容」，带数量、发送方与时间，可以保存、预览或复制；收到新内容时有提示。
- 手机上各部分自上而下排列，发送按钮固定在底部，触控目标不小于 44px，320px 宽度不出现横向滚动。
- 网络、协议、加密、分块续传、配额与权限逻辑没有改动。

## 升级说明

- 只需升级服务端即可用上新界面：Java、Go、.NET 服务端包内置管理后台与公开页面。C 服务端从 `SPECUS_STATIC_ROOT` 提供页面，需要指向本版构建出的前端；用 OpenResty 托管静态文件的部署需要换上本版的前端文件。
- 客户端不需要升级。v2.0.0 与本版的 Java、Go、.NET、Android 客户端行为一致。
- 互传的行为变化：选择文件后不再立即进入发送确认，而是先进入待发送列表，点发送按钮才开始；与升级前打开的旧页面互传不受影响。

## 验证与已知限制

- 前端单元测试 676 项；产品与互传的浏览器回归分别 12 项与 29 项（新增键盘发送、页面任意位置粘贴与拖放、待发送时离开页面的提醒等检查），均在 Chromium 中运行。页面在 1440 与 390 宽度、浅色与深色下逐页检查过截图。
- Safari、Firefox 与真机手机浏览器没有做人工验收。
- 专业流程图编辑器的页面没有改版；流量页的媒体播放器仍用原来的图标；TCP 帧列表仍没有检索条。
- 其余已知限制与 v2.0.0 相同，见 [v2.0.0 发布说明](v2.0.0.md)。
- 沿用全端发布流程；发布不代表已部署到运行中的服务器。Homebrew cask 在 devShuai/homebrew-specus 中另行更新。
