## 待办与验收方向

- [ ] 真实端到端连通性检查：区分已配置、设备在线、目标可达及访问成功；记录时间/失败阶段。只对用户显式选择的服务进行有界探测，不能由浏览器目录刷新冒充连接测试。
- [ ] 临时 HTTP 分享：有效期、撤销、访问范围与权限变更审计；各 server 实现保持一致，禁止把长期公开路由当作临时邀请。
- [ ] 大文件预检与离开提醒：前置 128 MiB 设备内存限制、可用传输方式、是否会上云、账号额度/有效期/一次性下载规则；待传内容存在时提醒离开，处理浏览器提醒能力限制。
- [ ] 分块续传：偏移/完整性校验、断线重连、重复块幂等、过期清理与接收方同意；明确刷新恢复与会话内重试边界，并跨浏览器、跨 NAT 验收。
- [ ] 服务工作台：常用服务、待处理问题、最近访问及统一发布入口；在线不等于目标可达，不自行扫描所有内网服务；收藏及历史按登录身份隔离。
- [ ] 产品指标：首次接入完成耗时、步骤流失、按文件大小区间/传输方式拆分成功率、失败重试成功率。默认关闭或显式选择开启，不记录凭证、文件名、文本内容或内网地址；明确保存期限与清除方式。

## 实施要求

按独立里程碑实施与验收；涉及后端的能力先确定协议、能力接口和隐私边界，再实施跨语言后端及前端。不宣称尚未部署的能力已经上线。

## 里程碑 1：发送前确认与离开提醒

### 已完成的前端部分（2026-09-06，本地验收）

- [x] 选择、拖入或粘贴文件后先暂存并展示发送前确认，不立即发送文件内容；取消不请求上传授权或预占额度。
- [x] 展示接收设备、文件名、逐个大小和总大小；可移除文件，拦截空文件、异常大小、单文件超过 128 MiB 的设备传输及超过 40 项的待发送队列。进行中的任务不会被完成记录挤出列表。
- [x] 确认和重试时复核原接收设备、房间、只读权限、在线状态及传输能力；设备离线时禁止发送，不自动换成另一台设备。
- [x] 默认仅尝试设备直连和 TURN 中转；远端设备失败后转临时存储须逐次明确授权，登录或重试不会扩大原授权。仍可主动选择生成文件链接，同局域网设备不自动回退到云端。
- [x] 如实说明内存限制、当前传输路径、临时存储边界及不支持断点续传；去除写死的 1 GiB 额度和“不扣额度”承诺。上传授权成功后显示服务端实际到期时间，区分文件到期、房间邀请到期和一次性下载授权。
- [x] 对待确认、排队、发送、失败待重试、接收待确认及未开始保存的直传文件显示页面离开提醒，并按需注册浏览器离开事件；不把完成的发送记录当成待传内容。明确浏览器可能抑制提示，刷新或关闭后不能恢复文件传输。
- [x] 桌面及 320px 手机布局可用；手机确认弹窗内容滚动，文件列表不会被压缩消失，操作按钮保持可达。

### 尚未完成的能力边界

- [ ] 设计并实现跨语言一致的只读额度/能力接口，提供实时剩余额度、上传限制及保留规则，再接入发送前确认。当前 API 不提供这些数据，前端显示“尚未确认”，实际上传仍可能被服务端拒绝；不得用上传授权接口冒充只读预检或偷偷预占额度。
- [ ] 完成上述接口对应的多 server 契约及集成验收后，再勾选“大文件预检与离开提醒”整体能力。
